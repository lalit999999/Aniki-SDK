# Aniki-SDK Documentation

Aniki-SDK is a TypeScript, provider-agnostic AI Agent SDK for building production-ready AI agents.
This is the documentation set: start with **Getting Started** if you're new, use **Core Concepts**
to understand how the pieces fit together, and use **Reference** when you need exact behavior,
error handling, or answers to specific problems.
